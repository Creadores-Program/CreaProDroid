### Project Description

This is an alternative F-Droid client based on the classic UI of the official F-Droid Client (pre-1.0), maintained and updated by **Creadores-Program**.

While modern client designs aim for visual flair, they can sometimes feel clunky or hide essential details behind multiple menus. This project is aimed at power users who value function over form, users running legacy hardware, or anyone who prefers the straightforward classic interface.

## Status

### What works
* **TLS 1.2 / 1.3 support** for older Android versions (Android 2.3+).
* 'index-v1' format support.
* **Privileged Extension** support.
* Inline changelogs.
* Screenshot viewer.
* Translation and donation links.
* Localized metadata.
* Numerous usability fixes and performance backports.

### Features NOT included
* Swap functionality.
* App auto-install via repo push.
* Tile-based modern UI.
* Legacy XML-based index format.

## FAQ

* **Does it work on old devices?**
  Yes! One of the main goals of this fork is to restore modern web/security standards (TLS 1.2 / 1.3) to allow F-Droid repositories to connect smoothly on legacy systems starting from **Android 2.3**.

* **How do I report issues or contribute?**
  Feel free to open an Issue or Pull Request directly in our [GitHub Repository](https://github.com/Creadores-Program/F-droid-Classic-Crea/issues) or discuss it in our [Discord Server](https://discord.com/invite/mrmHcwxXff).
